# Cloud Templates

`framework/capabilities/cloud` is now a fully implemented capability (see its own `README.md`), so this is no longer a placeholder for a future `execute()`. It generates vendor neutral deployment architecture; no `framework/providers/cloud/*` runtime adapter exists yet (still deferred, see `docs/architecture/ROADMAP.md` Phase 7C).

For a real starter Markdown template, see `templates/solution/cloud-deployment.md` (the `## Deployment Requirements` heading family). For completed worked examples, see `examples/solution/cloud-order-platform.md` and `examples/reference/order-platform.md`.
